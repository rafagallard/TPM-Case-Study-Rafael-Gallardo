# TPM Case Study — Rafael Gallardo

Interactive presentation of a Technical Project Manager case study that
decomposes an observable legal-directory page into user stories, assumptions,
dependencies, delivery phases, readiness criteria, and measurement areas.

## Published site

This repository is prepared for GitHub Pages and uses plain HTML and CSS. No
build process or external dependency is required.

## Source

The case study is based on observable behavior from the Avvo El Segundo, CA
Business Lawyers directory page. It does not claim knowledge of Avvo's private
architecture, proprietary ranking logic, commercial agreements, or internal
operating model.
